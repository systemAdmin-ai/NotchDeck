# Спецификация: локализация интерфейса NotchDeck (RU/EN) и выбор языка

Дата: 2026-11-16
Статус: к реализации
Основание: запрос владельца — «сделать английскую локализацию, выбор языка в настройках и в онбординге при установке».
Источники контекста: `Sources/*.swift` (25 файлов, 6912 строк), `build.sh`, `README.md`, `docs/GETTING_STARTED.md`.

## Цель

Интерфейс приложения доступен на русском и английском; язык выбирается при первом запуске (онбординг) и в настройках, по умолчанию — по языку системы. Английский интерфейс снимает главный блокер для Show HN, Product Hunt и r/macapps.

## Объём

- Слой локализации `Sources/L10n.swift`: перечисление языков, хранение выбора, загрузка таблицы переводов, функция `L(_:)`.
- Таблица переводов `Resources/en.lproj/Localizable.strings` (ключ = русская строка исходника).
- Замена всех пользовательских строк в UI на `L(...)`.
- Выбор языка: первый экран онбординга + новая вкладка «Общие» в настройках.
- Перерисовка интерфейса при смене языка без перезапуска.
- `build.sh`: копирование `.lproj` в бандл, компиляция `L10n.swift`.
- `Info.plist`: `CFBundleLocalizations`, `CFBundleDevelopmentRegion`.

## Требования и критерии приёмки

**R1. Хранение выбора языка.**
Ключ `NotchDeck.appLanguage` в `UserDefaults`, значения `system` / `ru` / `en`, по умолчанию `system`.
AC: `defaults read com.notchdeck.app NotchDeck.appLanguage` после выбора в настройках возвращает выбранное значение; при отсутствии ключа приложение работает (не падает) и использует системный язык.

**R2. Определение языка по системе.**
При `system` язык = `ru`, если первый предпочитаемый язык системы начинается с `ru`, иначе `en`.
AC: `LANG`/`AppleLanguages` = `(ru)` → интерфейс русский; `(en)` → английский. Проверяется командой `--l10n-report`.

**R3. Функция перевода и деградация.**
`L(_ key: String, _ args: CVarArg...) -> String`: при русском возвращает ключ как есть; при английском — перевод из таблицы; при отсутствии перевода возвращает ключ (русский текст), никогда не пустую строку и не сам ключ-идентификатор. При непустых `args` результат форматируется через `String(format:)`.
AC: `--l10n-report` печатает `missing=0` для всех ключей, использованных в коде; искусственно добавленный ключ без перевода возвращает исходную русскую строку (проверяется в `--l10n-report` на тестовом ключе).

**R4. Полнота перевода UI.**
Все пользовательские строки интерфейса обёрнуты в `L(...)`: онбординг, настройки (5 вкладок + новая), панель, плитки и их названия, медиаплеер, панели процессов/буфера/полки, диалоги записи экрана и микрофона, меню в строке состояния, окно профилей, быстрые заметки, статусы подключений, предупреждения HUD.
AC: скрипт проверки находит 0 русских литералов вне `L(...)` в перечисленных файлах; сборка проходит; рендер онбординга и настроек в режиме `en` не содержит кириллицы (проверка OCR/визуально по PNG).

**R5. Выбор языка в онбординге.**
На первом экране онбординга — выпадающий список из трёх пунктов: «Авто / Auto», «Русский», «English». Смена пункта немедленно перерисовывает текущий экран на выбранном языке.
AC: `--render-onboarding` с `appLanguage=en` даёт PNG с английским текстом; с `ru` — с русским; переключение в живом окне меняет текст без перезапуска.

**R6. Выбор языка в настройках.**
Новая первая вкладка «Общие» / «General» с тем же списком и пояснением, что язык применяется сразу.
AC: `--render-settings` создаёт 6 PNG (было 5), первый — вкладка «Общие» с элементом выбора языка.

**R7. Применение без перезапуска.**
Смена языка обновляет: меню в строке состояния, содержимое панели, окно настроек, открытое окно онбординга.
AC: после смены языка в настройках меню строки состояния и вкладки настроек показывают новый язык в том же запуске процесса.

**R8. Сборка и упаковка.**
`./build.sh` собирает приложение, `en.lproj/Localizable.strings` попадает в `NotchDeck.app/Contents/Resources/en.lproj/`.
AC: `ls Build/NotchDeck.app/Contents/Resources/en.lproj/Localizable.strings` — файл существует; `codesign --verify --deep --strict` проходит.

**R9. Совместимость настроек.**
Существующие ключи `UserDefaults` и профили не меняются; отсутствие `NotchDeck.appLanguage` не сбрасывает другие настройки.
AC: после запуска новой сборки на существующем профиле настройки (стиль панели, скрытые плитки, профили) сохраняются.

## Вне объёма

- Перевод вывода CLI-команд (`--selftest`, `--metrics`, `--procs-panel` и т. п.) и отладочных `NSLog`-строк — остаются на русском.
- Перевод `README.md`, `docs/*`, `CHANGELOG.md`, описания релиза.
- Третьи языки (de, fr, es и др.).
- Локализация имени приложения и `Info.plist` usage-описаний (остаются русскими; вынос в `InfoPlist.strings` — отдельная задача).
- Нотариализация и Developer ID (отдельный блокер продвижения).
- Автоматический перевод/машинный перевод на лету.

## Открытые вопросы

1. Нужны ли локализованные `NSAppleEventsUsageDescription` / `NSMicrophoneUsageDescription` в `InfoPlist.strings`? Сейчас остаются русскими — при английском интерфейсе системный запрос будет по-русски. Предложение: сделать следующей задачей.
2. Нужен ли третий пункт «Авто» отдельно от системного, или достаточно «Системный»? Принято «Авто / Auto» как понятное без перевода.

## Допущения

- Ключом перевода служит русская строка исходника: это позволяет не переписывать 380 строк в идентификаторы и сохраняет читаемость кода. Ограничение: изменение русского текста требует правки таблицы (фиксируется в отчёте).
- Форматируемые строки переводятся как format-строки с `%@` / `%d` / `%.0f`; проценты в тексте экранируются как `%%`.

# Версия для Mac App Store

Статус: черновик 2026-11-19, требует решений по открытым вопросам.
Владелец: systemAdmin-ai. Приложение: NotchDeck 2.1.1 (221), arm64, macOS 14+.

## Задача

Сделать сборку, которую можно выложить в Mac App Store, чтобы пользователь нажимал
«Загрузить» и получал приложение без предупреждений Gatekeeper, без Homebrew и без
самостоятельного снятия карантина. Основной канал (DMG + нотаризация) при этом
не ломается и продолжает жить.

Причина отдельной сборки: Mac App Store требует App Sandbox, а внутри песочницы
запрещены приватные фреймворки и API, закрытые привилегией Accessibility.
Текущая сборка использует и то, и другое.

## Что уходит и чем заменяется

| Сейчас | Файл | В стор-сборке |
|---|---|---|
| `dlopen` DisplayServices — чтение и установка яркости | `Sources/SystemControl.swift:6,22-26` | убрать; яркость только ступенями через публичные клавиши яркости (`CGEvent`, `NX_KEYTYPE_BRIGHTNESS_UP/DOWN`), процент не показывать |
| `dlopen` MediaRemote — play/pause/next | `Sources/SystemControl.swift:216-232` | `MPRemoteCommandCenter` |
| NSAppleScript к Music/Spotify/QuickTime — «сейчас играет» | `Sources/NowPlaying.swift:36-62` | `MPNowPlayingInfoCenter`; AppleScript убрать целиком |
| SMC через IOKit — температура | `Sources/Metrics.swift:1-22` | убрать: в песочнице AppleSMC недоступен, temporary-exception отклоняется ревью |
| `AXIsProcessTrusted()` как условие тапа | `Sources/Keys.swift:50` | `CGPreflightListenEventAccess()` / `CGRequestListenEventAccess()` |
| DistributedNotification-триггеры для проверок | `Sources/Panel.swift:284-296` | исключить из стор-сборки |
| Запись экрана в произвольный путь | `Sources/Capture*` | только контейнер приложения либо путь из `NSSavePanel` |
| Самообновление из DMG | `scripts/`, `main.swift` | в стор-сборке отсутствует: обновления только через стор |

Остаётся без изменений: панель в чёлке (AppKit, `NSPanel`), `LSUIElement`, громкость
через CoreAudio, перечисление клавиатур через `IOHIDManager` (совместимо с песочницей
при разрешении «Мониторинг ввода»).

## Ключевой факт для проверки

Песочницу можно включить и проверить **сегодня**, без оплаты Apple Developer Program:
`com.apple.security.app-sandbox` работает с любым сертификатом, включая локальный.
Оплата нужна только для сертификата Apple Distribution и загрузки. Поэтому все
требования ниже, кроме R10, проверяются до траты денег.

## Проверено 2026-11-19

Тестовый процесс, подписанный с `com.apple.security.app-sandbox`, при попытке открыть
приватный фреймворк DisplayServices был убит песочницей (сигнал 5, код возврата 133).
Тот же код без песочницы читает яркость: `rc=0 brightness=0.8125`.

Вывод: песочница действительно закрывает приватные фреймворки, и проверка R2
воспроизводится локально до какой-либо оплаты.

## Требования и критерии приёмки

**R1. Отдельная сборка, основной канал не тронут.** `./build.sh --mas` собирает
`Build/MAS/NotchDeck.app` с песочницей; `./build.sh` без флагов даёт прежнюю сборку.
Критерий: `codesign -d --entitlements - Build/MAS/NotchDeck.app` содержит
`com.apple.security.app-sandbox = true`; `codesign --verify --strict` проходит;
Activity Monitor показывает Sandbox = Yes; обычная сборка подписана тем же
сертификатом, что и раньше.

**R2. В бинаре нет приватных фреймворков.** Критерий:
`strings Build/MAS/NotchDeck.app/Contents/MacOS/NotchDeck | grep -cE 'PrivateFrameworks|DisplayServices|MediaRemote'`
даёт 0; то же для `dlopen` в исходниках стор-таргета.

**R3. Яркость работает без приватного API.** Неон показывает изменение ступенями
(не менее 8 градаций), процент не выводится. Критерий: нажатие клавиш яркости меняет
яркость системы; HUD появляется и гаснет; в логе нет обращений к DisplayServices.

**R4. Медиа через публичные API.** play/pause/next работают для Music и Spotify;
название трека и обложка берутся из системы. Критерий: команды выполняются;
`grep -c MediaRemote` по исходникам стор-таргета = 0.

**R5. Никакого Accessibility-гейта.** Критерий: `grep -c AXIsProcessTrusted` по
исходникам стор-таргета = 0; доступ запрашивается через
`CGRequestListenEventAccess()`; после перезапуска приложения перехват работает
без повторной выдачи.

**R6. Перехват клавиш.** Блокирующий тап (`CGEvent.tapCreate` c `.defaultTap`) остаётся,
но должен быть выключаемым: настройка «не блокировать системные сочетания» переводит
приложение на Carbon `RegisterEventHotKey`.
По сторонним измерениям блокирующий тап в песочнице создаётся, но нами это не
проверено — до проверки считать рискованным.
Критерий: при выключенной настройке сочетания срабатывают у системы и у приложения;
при включённой — приложение забирает их себе.

**R7. Файлы только в контейнере.** Критерий: после сессии работы в
`~/Library/Containers/com.notchdeck.app/Data/` есть логи и временные файлы;
в `~/Library/Logs`, `/tmp`, `~/Movies` приложение ничего не создаёт; запись экрана
сохраняется только по пути, выбранному пользователем.

**R8. Никакого самообновления.** Критерий: в стор-сборке нет кода, скачивающего и
устанавливающего обновления; пункт меню «Проверить обновления» отсутствует или ведёт
в App Store.

**R9. Метаданные и приватность.** Есть `PrivacyInfo.xcprivacy` с перечнем
required-reason API; строки использования в Info.plist соответствуют фактическим
привилегиям (микрофон, запись экрана, мониторинг ввода); лишних строк нет.
Критерий: файл присутствует в бандле, `plutil -lint` проходит, набор строк совпадает
с набором используемых API.

**R10. Пакет принимается App Store Connect.** `productbuild` собирает `.pkg`,
подписанный сертификатом установщика; `xcrun altool --validate-app` не возвращает
ошибок. Критерий: валидация проходит (выполняется после получения сертификатов
Apple Distribution).

## Вне области

- Покупки и подписки внутри приложения.
- Новые языки интерфейса и редизайн.
- iOS/iPadOS-версия.
- Изменение функциональности основного канала (DMG, Homebrew).
- Нотаризация основного канала — отдельная задача.

## Открытые вопросы

1. **Яркость.** Убрать индикатор совсем или оставить ступени без процента? От этого
   зависит, останется ли «неон» узнаваемым. Рекомендация: ступени.
2. **Температура.** Убрать из стор-сборки насовсем или оставить пункт с честной
   надписью «недоступно в версии из App Store»?
3. **Оплата.** Готов ли владелец платить 99 долларов в год и проходить проверку
   торговца по DSA (для ЕС) — без неё приложение вырезают из европейского стора?
4. **Громкость.** Нужно эмпирически проверить, разрешает ли песочница менять системную
   громкость через CoreAudio. Если нет — остаются только медиа-клавиши.
5. **Bundle ID.** Оставляем `com.notchdeck.app` для обоих каналов или стор-версия
   получает `com.notchdeck.app.store`? Один идентификатор проще, но тогда оба канала
   должны обновляться согласованно.
6. **Цена и категория** в App Store Connect.

## Риски ревью

- **2.5.1** — приватные API. Закрывается R2: в бинаре не должно остаться ни строк, ни
  символов приватных фреймворков.
- **2.4.5** — «Accessibility не для целей доступности». Основной риск для блокирующего
  тапа. Смягчение: R6 (выключаемый перехват) и честное описание в метаданных.
- **2.4.5(i)** — обязательная песочница. Закрывается R1.
- **4.2** — «минимум функциональности». Панель в чёлке плюс медиа плюс клавиатура
  этот порог проходят, но описание должно показывать ценность, а не одну фичу.

## Процесс подачи (когда код готов)

1. Apple Developer Program, 99 долларов в год; для юрлица — D-U-N-S.
2. Регистрация App ID `com.notchdeck.app`, создание записи в App Store Connect.
3. Сертификаты Apple Distribution и Apple Distribution Installer; профиль.
4. Сборка `--mas`, подпись, `productbuild`, валидация.
5. Privacy manifest, метки приватности, возрастной рейтинг, статус торговца DSA.
6. Скриншоты, описание, категория, цена.
7. Загрузка (Xcode Organizer, Transporter или `altool --upload-package`), TestFlight,
   подача на ревью.

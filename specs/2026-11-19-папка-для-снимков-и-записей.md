# Папка для снимков и записей экрана

Статус: в работе, 2026-11-19. Приложение: NotchDeck 2.2.0 (230), arm64, macOS 14+.

## Задача

Сейчас и снимки, и записи жёстко пишутся в `~/Desktop/Screenshots` (`Tools.swift`, `Capture.folder`).
Пользователь не может выбрать другое место: часть людей держит рабочий стол чистым или складывает
записи на внешний диск. Нужна настройка папки в интерфейсе, применяемая сразу и переживающая
перезапуск. Изменение уходит в публичный репозиторий, поэтому дефолт обязан остаться прежним —
у существующих пользователей ничего не должно поменяться молча.

## Требования и критерии приёмки

**R1. Дефолт не меняется.** Если настройка не задана, файлы по-прежнему идут в
`~/Desktop/Screenshots`, которая создаётся при необходимости.
Критерий: на чистом профиле `--capture-folder` печатает `~/Desktop/Screenshots`,
`по умолчанию=true`; старое поведение воспроизводится.

**R2. Настройка в интерфейсе.** В «Настройках» появляется отдельная вкладка «Запись»:
текущий путь, кнопки «Изменить…» (выбор папки), «Открыть в Finder», «По умолчанию» (сброс).
Критерий: вкладка присутствует в `--render-settings` (число вкладок выросло на одну),
кнопки видны и подписаны; «Изменить…» открывает диалог выбора папки.

**R3. Хранение и применение без перезапуска.** Путь хранится в `UserDefaults` под ключом
`NotchDeck.captureFolder`; пустое значение означает «по умолчанию». Смена папки действует
на следующий снимок и следующую запись, без перезапуска приложения.
Критерий: `defaults write com.notchdeck.app NotchDeck.captureFolder <path>` меняет результат
`--capture-folder` и путь файла из `--shot-rect`; после сброса снова дефолт.

**R4. Недоступная папка не ломает запись.** Если папки нет — создаём. Если создать или писать
нельзя (нет прав, диск отключён) — откат на папку по умолчанию, одна запись в отладочный лог,
файл всё равно сохраняется.
Критерий: при `captureFolder=/Volumes/НетТакогоДиска/xx` `--shot-rect` кладёт файл
в `~/Desktop/Screenshots`; в логе есть строка `capture: папка недоступна`.

**R5. Локализация.** Новые строки идут через `L(...)`, английские переводы добавлены
в `Resources/en.lproj/Localizable.strings`.
Критерий: `--l10n-report` не показывает пропущенных ключей для новых строк, `--l10n-switch-test`
работает без падений.

**R6. Прежние проверки не сломаны.** Критерий: `scripts/check.sh` проходит целиком,
подпись `codesign --verify --deep --strict` валидна.

## Вне области

- Автоматическое открытие папки после сохранения.
- Отдельные папки для снимков и для записей (одна на оба типа).
- Настройка имени файлов и шаблона даты.
- Перенос уже сохранённых файлов при смене папки.
- Публикация релиза и обновление cask — отдельная задача.

## Открытые вопросы

1. Нужны ли отдельные папки для снимков и для записей? Пока одна, по обоим типам.
2. Показывать ли путь в самой панели чёлки, или только в настройках? Пока только в настройках.

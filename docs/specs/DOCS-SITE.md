# Документация и интерактивное демо · SDD

17 ноября 2026. Требования к сайту документации NotchDeck в репозитории.

## R1 — Статический сайт без сборки
`docs/index.html` открывается как обычный файл и работает на GitHub Pages без сборки,
npm и внешних CDN. Все стили и скрипты — внутри документа, шрифты системные.

**Приёмка:** страница открывается локально (`file://`) и по адресу Pages; в коде нет
`http://`/`https://` ссылок на сторонние скрипты, шрифты и стили.

## R2 — Навигация
Постоянный список разделов (обзор, установка, возможности, клавиатура, оформления,
скриншоты, сборка, демо), плавный переход по якорям, подсветка текущего раздела при
прокрутке, кнопка «наверх». На узком экране список сворачивается в верхнее меню.

**Приёмка:** клик по пункту прокручивает к разделу; активный пункт меняется при
прокрутке; при ширине < 900 px навигация не перекрывает текст.

## R3 — Анимации
Появление секций при прокрутке, мягкое свечение кромки панели, бегущий импульс
зарядки, «дыхание» неонового индикатора. При `prefers-reduced-motion: reduce`
анимации отключаются, содержимое остаётся видимым.

**Приёмка:** при включённом reduced-motion нет циклических анимаций; без него —
секции появляются один раз, свечение и импульс видны.

## R4 — Язык
Переключатель RU/EN без перезагрузки: переводится весь текст сайта, включая
подписи демо. Выбор сохраняется в `localStorage`.

**Приёмка:** переключение меняет заголовки, тексты и подписи; после перезагрузки
язык прежний; в разметке нет непереведённых абзацев.

## R5 — Интерактивное демо чёлки
`docs/demo.html`: наведение на чёлку раскрывает панель, уход — сворачивает; клик
фиксирует открытое состояние. Внутри работают: плитки показателей, профили
(Работа/Видео/Запись), ряд действий, кнопка «Клавиатура» с зелёной подсветкой и
подсказкой, индикаторы яркости и громкости с перетаскиванием, предупреждение и
импульс зарядки, смена оформления из пяти.

**Приёмка:** панель раскрывается и сворачивается; переключение клавиатуры меняет
подсветку и статус; ползунок HUD двигается мышью и клавиатурой (стрелки, Home и End); смена
оформления визуально меняет панель; ошибок в консоли нет.

## R6 — Никаких личных данных
Демо использует только синтетические значения: вымышленные имена приложений,
никаких реальных имён пользователя, путей, VPN-статусов и сетевых адресов.

**Приёмка:** grep по `docs/*.html` не находит домашних путей, адресов и личных имён.

## R7 — Публикация
GitHub Pages включён из ветки `main`, каталог `/docs`. В `README.md` и `README.ru.md`
добавлены ссылки на сайт и демо, в описании репозитория указан адрес сайта.

**Приёмка:** `https://systemAdmin-ai.github.io/NotchDeck/` отдаёт 200 и тот же HTML,
что в репозитории; `demo.html` открывается с сайта; ссылки в README ведут на Pages.

## Вне области
- Отдельные страницы для каждой функции, поиск по документации, тёмная/светлая тема сайта.
- Английская версия демо как отдельный файл (перевод — внутри страницы).
- Автоматическая сборка сайта из Markdown.

## Открытые вопросы
- Нужен ли домен вместо адреса `github.io` (требует DNS и настройки в репозитории).
- Публиковать ли демо в карточке appstorrent как «интерактивный предпросмотр».

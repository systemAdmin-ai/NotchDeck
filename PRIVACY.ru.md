# Конфиденциальность

English version: [PRIVACY.md](PRIVACY.md)

NotchDeck работает локально. В приложении нет аккаунтов, аналитики, телеметрии,
серверной синхронизации или отправки заметок, файлов и записей разработчику.

| Данные | Где находятся | Когда используются |
|---|---|---|
| Настройки и выбранные приложения | UserDefaults текущего пользователя, домен `com.notchdeck.app` | Для восстановления панели |
| Быстрые заметки | UserDefaults текущего пользователя | При открытии и редактировании заметок |
| Ссылки на файлы на полке | UserDefaults текущего пользователя | После добавления файлов на полку |
| История буфера | Только оперативная память, до 30 элементов | Только после включения пользователем; при выключении очищается |
| Снимки и записи | `~/Desktop/Screenshots` | Только по действию пользователя |
| Показатели и статусы VPN | Читаются локально | Для отображения в панели |
| Яркость фона за неоном | Узкая верхняя полоса экрана, уменьшенная до 256×24; только память процесса | При видимом ореоле и уже выданном доступе к экрану; без сохранения кадров |
| Медиа и обложка | Метаданные проигрывателя macOS, память процесса | При воспроизведении |

Микрофон выключен по умолчанию. Его можно выбрать перед записью; macOS отдельно
запрашивает доступ. Автозапуск также включается только пользователем.

Отладочный лог выключен по умолчанию. Даже в отладочном режиме содержимое
буфера обмена не записывается в лог. Не отправляйте личные заметки, записи,
пути к файлам или логи в публичные issues. Для сообщения об ошибке достаточно
версии macOS, версии приложения и шагов воспроизведения.

В установщике и репозитории отсутствуют пользовательские plist, заметки,
история буфера, ссылки на личные файлы, записи экрана и локальные логи.
macOS управляет разрешениями отдельно; они не переносятся вместе с приложением.
